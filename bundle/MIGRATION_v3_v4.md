# Migration SDLC v3.x → v4.0

v4.0 rewrites the framework's instructions in English and tunes them for Claude Opus 5.5.
The workflow, file names, IDs, commands and gates are unchanged. Existing v3 projects keep
validating without edits; the steps below are optional clean-ups.

---

## What changed

| Area | v3.x | v4.0 |
|---|---|---|
| Instruction language | French | English (skills, commands, agents, references, scripts) |
| Artifact language | French | Project's `output_language` (default: the language you write in) |
| `sdlc-config.json` | `"version": "3.2"` | `"version": "4.0"` + optional `output_language` |
| Model IDs | `claude-sonnet-4-6`, `claude-opus-4-7` | `claude-sonnet-5`, `claude-opus-5-5` (Haiku: `claude-haiku-4-5`) |
| Agent frontmatter | no `effort` | `effort:` per tier (`low` / `medium` / `high`) |
| `/sdlc:dev` flag | `--vague N` | `--wave N` (`--vague N` still accepted) |
| Field markers | `**Dépend de**`, `**Fichiers cibles**` | `**Depends on**`, `**Target files**` (French still accepted) |

Agent `effort` defaults: `low` for `sdlc-code-auditor` and `sdlc-archive-manager`; `high` for
`sdlc-architect` and `sdlc-discussion-facilitator`; `medium` for the others. Edit the agent
file in `~/.claude/agents/` to override.

---

## Upgrade

1. Update the bundle:

   ```bash
   cd sdlc-framework
   git pull
   pwsh bundle/scripts/install.ps1      # or: bash bundle/scripts/install.sh
   ```

   The installer backs up every file it replaces under `~/.claude/_backups/`. If you edited
   installed files locally, capture them first (`docs/SYNC.md`).

2. Restart Claude Code.

3. Optional, per project: edit `SDLC_PM/sdlc-config.json`:

   ```json
   {
     "version": "4.0",
     "output_language": "fr"
   }
   ```

   (merge these two keys into your existing config). Without `output_language`, artifacts
   are written in the language you write in.

4. Optional: if your config pins models in `model_overrides`, replace `claude-sonnet-4-6`
   with `claude-sonnet-5` and `claude-opus-4-7` with `claude-opus-5-5`.

5. Run `/sdlc:gate` to confirm the project still passes.

## Compatibility

- **Legacy markers**: `check_sdlc.py` (AQ Gate) and `wave_planner.py` accept both
  `**Depends on**` / `**Target files**` and the v3 French markers `**Dépend de**` /
  `**Fichiers cibles**`. You do not need to rewrite existing `3_conception.md` files; new
  files generated by v4.0 use the English markers.
- **File names** (`1_elicitation.md`, `3_conception.md`, `HANDOFF.md`, …), IDs
  (`E###`, `A###`, `P###`, `T###`), statuses (⬜ 🔄 ✅ 🔁 🚫) and config keys are unchanged.
- **Scripts**: flags and exit codes of `install`, `uninstall`, `verify`, `capture`,
  `restore` and `scan-fuites` are unchanged; only their messages are now in English. If you
  parse their output, note the renamed labels: verify markers `[MISSING]` / `[EXTRA]` /
  `[FLOOR]` (were `[MANQUANT]` / `[SURNUMERAIRE]` / `[PLANCHER]`; `[HASH DIFF]` is unchanged)
  and sync states such as `modified-both`, `modified-live`, `added-live`, `deleted-ref`
  (were `modifie-des-deux`, `modifie-live`, `ajoute-live`, `supprime-ref`). The installer now
  ends with `Installation complete` (was `Installation terminee`).

## Rollback

Check out the last v3.x commit of the repository and run the installer again; it backs up
the v4.0 files before replacing them.
